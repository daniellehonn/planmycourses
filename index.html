📋 Setup Instructions

Step 1: Access the Template

  2. Click File → Make a copy to create your own editable version

Step 2: Customize Your Course List

Replace the sample data with your own courses

✨ PLEASE NOTE: If you have fulfilled a course elsewhere (eg. CC, AP, IB, etc.), please don't include it in your course list or list it as a prerequisite/corequisite!

For each course, fill in:

  1. Course Name & Number (e.g., "CS 101"):
  2. Taken:
    • Write Not Assigned if you haven't taken it yet
    • Otherwise, use format like: "Fall, Year 1"
  3. Req Satisfied:
    • The requirement category this course satisfies
    • Examples: Lower Div, Major Core, 5 Elective, GE, TB
  4. Prerequisites (courses that must be taken before this one):
    • List course numbers separated by commas
    • ⚠️: These must exactly match the course names elsewhere in the spreadsheet
  5. Corequisites (courses that must be taken together):
    • List course numbers separated by commas
    • ⚠️: These must exactly match the course names elsewhere in the spreadsheet
  6. Units: How many units the course is worth

✨ Pro Tip: Put your most important courses at the top — the planner uses this order to prioritize!

Step 3: Export Your Data

  1. In your Google Sheet, go to File → Share → Publish to web
  2. In the dropdown menu, change from "Entire Document" to your specific sheet/tab
  3. In the dropdown menu, change from "Web page" to "Comma-separated values (.csv)"
  4. Click Publish and copy the generated link

Step 4: Connect to Course Planner

  1. Paste the copied link into the Load Course Data field

Important: Verify the link ends with output=csv before submitting

🎉 Congrats! Your course planner is now ready to go!

Graduation Requirements

How many courses and/or units each category actually needs to graduate. Leave both blank to use however many courses you've listed. Use Units for a requirement that's unit-based rather than course-based (e.g. 12 units of upper-division electives, however many courses that takes) — the dashboard tracks units instead of course count once set. Auto-plan stops scheduling a category once every target you've set for it is met.
